# HarmoniRT — Modul 1 Kependudukan & Mutasi Warga (React + Vite)

Rebuild dari `design/modul_1_kependudukan_mutasi_warga/code.html`.

## Jalankan
```bash
cd harmoni-rt
npm install
npm run dev
```
Buka http://localhost:5173

## Fitur
- Sidebar + header + navigasi mobile (hamburger)
- 5 kartu metrik demografi
- Tabel KK dengan search (nama/NIK/nomor KK), filter status & blok
- Drawer rincian anggota keluarga per KK
- Modal Tambah KK dan Lapor Mutasi
- Timeline mutasi + widget demografi umur
